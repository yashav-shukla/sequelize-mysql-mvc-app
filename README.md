## 📖 Overview

This project demonstrates how to connect Sequelize ORM with MySQL using Node.js and follow the MVC architecture pattern.

---

## ✨ Features

✅ Sequelize ORM Integration

✅ MySQL Database Connection

✅ MVC Folder Structure

✅ Student Model Creation

✅ Automatic Table Synchronization

✅ MySQL Workbench Verification

---

## 🛠 Tech Stack

* Node.js
* Express.js
* Sequelize ORM
* MySQL
* MySQL2

## 📦 Installation

```bash
npm install
```

Install Required Packages

```bash
npm install express sequelize mysql2
```

---

## ⚙️ Run Project

```bash
node app.js
```

or

```bash
npx nodemon app.js
```

---

## 🗄️ Create Database

```sql
CREATE DATABASE sequelize_db;
```
